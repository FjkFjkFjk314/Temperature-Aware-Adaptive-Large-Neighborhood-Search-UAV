# 动态6点 vs 静态低温三类图说明

本文档说明以下三张图的含义、读图方式和可用于论文/报告的结论表述：

- `低温对比_01_Objective配对哑铃图_1.png`
- `低温对比_01_Objective配对哑铃图_2.png`
- `低温对比_02_改善率排序条形图.png`

## 1. Objective 配对哑铃图

对应文件：

- `低温对比_01_Objective配对哑铃图_1.png`
- `低温对比_01_Objective配对哑铃图_2.png`

该图用于展示同一个算例下，动态6点规划与静态低温规划的 Objective 一一配对对比。

图中每一行代表一个算例组合，标签格式为：

```text
Weather-Platform-Case
```

例如：

```text
Real-Single-C101_100
```

表示真实温度场景、单平台、`C101_100` 算例。

图中两个点的含义为：

- `Static Low Temperature`：静态低温规划的 Objective；
- `Dynamic 06:00`：动态6点规划的 Objective。

横轴为 Objective，数值越低表示方案越优。若红色的 `Dynamic 06:00` 点位于灰色的 `Static Low Temperature` 点左侧，说明动态6点规划在该算例上获得了更低的目标函数值。

该图的优势是保留了“同一算例配对比较”的关系，避免把不同算例的绝对 Objective 直接混在一起比较。由于每个算例内部只比较两种规划方式，因此更适合展示算法改进是否稳定存在。

从图中可以观察到，大多数算例中红色点位于灰色点左侧，说明动态6点规划相对静态低温规划通常能够降低 Objective。少数红色点位于右侧的算例表示动态6点规划在该算例上的 Objective 略高于静态低温规划。

适合用于论文/报告中的表述：

```text
The dumbbell plots compare Static Low Temperature and Dynamic 06:00 planning on a case-by-case basis. 
For most instances, the Dynamic 06:00 point is located to the left of the Static Low Temperature point, 
indicating a lower objective value under dynamic planning.
```

中文表述可写为：

```text
Objective 配对哑铃图显示，在大多数算例中，动态6点规划的 Objective 低于静态低温规划，说明动态规划能够在低温约束下获得更优的目标函数值。
```

## 2. 改善率排序条形图

对应文件：

- `低温对比_02_改善率排序条形图.png`

该图用于展示动态6点规划相对静态低温规划的 Objective 改善率，并按改善率从低到高排序。

改善率计算公式为：

```text
Improvement (%) = (Objective_static_low - Objective_dynamic_06) / Objective_static_low * 100%
```

其中：

- `Objective_static_low` 表示静态低温规划的 Objective；
- `Objective_dynamic_06` 表示动态6点规划的 Objective。

读图方式如下：

- 条形位于 0 右侧：动态6点规划 Objective 更低，说明动态规划优于静态低温规划；
- 条形位于 0 左侧：动态6点规划 Objective 更高，说明该算例上动态规划未取得 Objective 优势；
- 条形越长：改善幅度越大；
- 红色条形：动态6点规划取得正改善；
- 蓝色条形：动态6点规划改善率为负。

该图相比哑铃图更适合突出“优势大小”。它可以直接看出哪些算例中动态规划收益最大，也可以观察动态规划优势是否集中在某些天气、平台或算例规模上。

从统计结果看，动态6点相对静态低温在 48 组对比中有 43 组 Objective 更优，胜率为 89.6%，平均改善率为 11.22%。因此该图可以作为展示总体优势和高改善算例的核心图。

适合用于论文/报告中的表述：

```text
The improvement ranking plot shows that Dynamic 06:00 planning outperforms Static Low Temperature planning in 43 out of 48 paired comparisons, 
with an average objective improvement of 11.22%.
```

中文表述可写为：

```text
改善率排序图显示，动态6点规划在 48 组配对对比中有 43 组取得更低 Objective，胜率为 89.6%，平均改善率为 11.22%，表明动态规划相对静态低温规划具有稳定优势。
```

## 3. 三张图的推荐使用方式

建议将这三张图按以下顺序使用：

1. 先放 `Objective 配对哑铃图`，说明每个算例内部动态6点与静态低温的直接对比关系；
2. 再放 `改善率排序条形图`，量化动态6点相对静态低温的改善幅度；
3. 若版面有限，优先保留 `改善率排序条形图`，因为它同时包含优势方向和优势大小。

推荐图注：

```text
Figure X. Comparison between Dynamic 06:00 planning and Static Low Temperature planning. 
The dumbbell plots show paired objective values for each instance, while the improvement ranking plot reports the relative objective reduction of Dynamic 06:00 planning.
```

中文图注：

```text
图 X. 动态6点规划与静态低温规划对比。配对哑铃图展示各算例下两种规划方式的 Objective 对比，改善率排序图展示动态6点规划相对静态低温规划的 Objective 相对降低幅度。
```

## 4. 结论重点

这三张图共同强调的结论是：

```text
Compared with Static Low Temperature planning, Dynamic 06:00 planning achieves lower objective values in most paired instances and shows a clear advantage under low-temperature constraints.
```

对应中文结论为：

```text
相比静态低温规划，动态6点规划在大多数配对算例中取得了更低的 Objective，说明其在低温约束条件下具有更稳定的优化优势。
```
