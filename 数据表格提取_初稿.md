## 2. Main-text table: experimental settings

**Table 1. Experimental parameters and scenario settings.**

| Item | Setting used in this study |
| --- | --- |
| Benchmark instances | 12 Solomon instances: C101, C201, C102, C202, R101, R201, R102, and R202 with 25, 50, or 100 customers. |
| Platform scenarios | Single-platform setting uses the original depot only; multi-platform setting adds two platforms at (20, 30) and (57, 31). |
| Weather scenarios | Real-weather scenario uses Shenyang hourly temperature on 2024-01-01 smoothed to minute-level values; synthetic cosine weather is used as a controlled supplementary scenario. |
| Temperature settings | Static baselines use representative fixed temperatures; dynamic runs use a fixed dispatch start at 00:00 with temperature reference times at 06:00, 08:00, and 14:00. |
| UAV and battery model | Nominal range = 240; maximum payload = 200; main battery-efficiency model = M7 V-shaped function. |
| Solver and repetitions | ALNS_1 with cluster-based initialization; each case is repeated 5 times. |

Note: Detailed cost parameters, ALNS iteration parameters, random seed, and exact temperature values are reported in Table A1. In all result tables, `N` denotes the number of paired instances or paired cases included in the aggregation, not the number of customers.
